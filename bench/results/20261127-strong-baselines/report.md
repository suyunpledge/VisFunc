# 动效强基线对照

2026-11-27，冻结的 Qt 合成留出 12 段和 Chrome 录屏留出 12 段。三种模型在 24 段素材上分别作答，Qt 另做探针组，共 396 个独立任务。所有条件均使用相同的真值和评分。在只依赖视觉输入的五个条件中，视频加测量摘要的场景分数和交付成功率最高，中位耗时最短。成功返回有效回答的一些 OpenCV 和函数工具会话也能达到很高的分数。

### 误差与交付

| 条件 | 有效答案 | 格式失败 | 接口失败 | 工具协议失败 | 输入 / 输出 token 中位数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| V0 | 60 | 10 | 2 | 0 | 1,523 / 338 |
| V1 | 49 | 21 | 2 | 0 | 1,735 / 612 |
| V2 | 39 | 23 | 10 | 0 | 5,542 / 903 |
| V3 | 69 | 3 | 0 | 0 | 2,188 / 98 |
| V4 | 50 | 17 | 4 | 1 | 3,900 / 232 |
| V5 | 35 | 1 | 0 | 0 | 1,862 / 101 |

有效 JSON 里的错误字段和缺测字段单独计数。模型显式返回 `null` 时按缺测计分，独立分析器的历史口径允许无位移通道表示静止。完整裸数组可解析，另记一次外壳偏离。接口失败含连接或计数预检失败，工具协议失败指模型首轮未发出合法工具请求。基础设施重试的回执、token 与耗时全部保留。上表耗时是每个任务各次尝试之和的中位数，含 V2 沙盒与 V4 查询，用量含多轮重复输入，V1/V3/V4 的本地素材预处理单列。24 段复算中，生成文字摘要及函数包的中位耗时为 1.74 秒，预制全部密集帧候选为 0.30 秒，读取 Qt 属性轨迹并生成探针摘要为 0.11 秒。24 段摘要均与送测内容一致。

- **密集帧**。GPT 在 Qt 的 V1−V0 为 +13.4 个百分点（5.1 至 23.1），浏览器为 +4.2（0.0 至 11.1）。GPT 和 MiMo 的密集帧中位数均为 66.5 帧，Seed 为 24 帧。按实测首轮 token，V1/V3 比值落在 0.8–1.2 的样本为 GPT 6/24、MiMo 10/24、Seed 21/22。GPT 和 MiMo 的多数候选已用尽原片的可用帧，仍有预算余量。Seed 有一条开发校准调用超时，使用另一条开发样本校准。MiMo 的 21 个失败均在返回空文本时达到 3,000 输出 token。随后同媒体关闭思考模式抽查 4 个失败样本，3 个返回有效 JSON，1 个仍格式无效。抽查用于诊断输出上限，分数保留原有会话的结果。
- **模型写代码测量**。V2 共运行 84 次脚本，77 次退出码为零，端到端 39/72 返回有效答案。在九个能交付答案的 GPT 浏览器样本上，九个全项正确。GPT 浏览器 V2 端到端分数为 75.0%，V3 为 98.6%，中位耗时分别 28.73 秒和 10.15 秒。有效输出子集随条件变化，子集正确率有选择偏差。
- **函数查询**。V4 有 21 个任务发出正式数值查询，GPT 的任务在拿到目录后直接作答。目录已经含区间、取值范围和估计设计时序，因此 V4 比较的是当前目录与查询交互的端到端效果。有效答案子集上，GPT 的 V4 为 Qt 96.4%、浏览器 100.0%，V3 为 95.8%、98.6%。整体差距主要来自额外轮次和交付失败。当前样本支持将摘要作为优先入口，对函数查询本身的收益还需单独设计任务验证。
- **布局重排**。同一批素材的独立视觉分析器得分为 Qt 64.0%、浏览器 72.2%。浏览器六个重排场景均未被独立分析器完整测准。GPT 加上视频后在五个重排场景全项正确，Seed 和 MiMo 的 V3 重排场景得分均为 44.4%。后续算法验收应继续直接与重排真值比对，并独立看边界、尺寸和漏段。模型结合画面能纠正部分测量缺口。

### 素材、隔离与计费

各来源六个家族各两段，每段真值来自和视频同次渲染或录屏。样本、时间戳和媒体哈希收在回执与清单中。录像是短篇本地页面和 Qt 测试场景，适用范围为该类 UI 动效。原生输入请求 MiMo 10fps、Seed 5fps，实际抽取由服务方决定。GPT 使用从 0 到约 700ms、间隔约 100ms 的八张帧图，较长尾部覆盖于 V1，V0 供历史比较。V1 用像素差定位变化区域后制带时间戳的图块，图块转回源坐标的尺寸与偏移随请求发送。V2 只向脚本进程提供该段视频，容器断网、根文件系统只读、没有主机挂载，单脚本限 12 秒，每任务最多两次。V4 只查询这段视频的函数包。模型各条件的历史分开，每次基础设施重试均新开同条件会话。评分端单独解包真值。

MiMo 走 Forge 的 Token Plan。Seed 锁定 Forge「豆包多模态测试」槽位，路径为 `/api/plan/v3`，所有成功回执均确认服务版本为 `doubao-seed-2-1-pro-260915`。`/api/coding/v3` 是另一槽位。单独原生视频复核返回 200，输入 2,383 token。 [原生视频复核](seed-multimodal-canary.json)
