# M1 尺寸和布局重排验收

2026-11-27。在冻结跟踪逻辑后，重新渲染了 30 段 Qt 视频，并从 12 个本地 Chrome 页面重新采集录屏和同次动画真值。开启四边跟踪后，16 个重排场景全部测准，包括尺寸、被推动元素的位移、时间和缓动。新留出集共 63 个真值动效，漏段从 16 个降至 0 个，额外片段为 0。API 费用为零。

## 尺寸原来在哪里丢失

规格、摘要和函数编译器都已支持宽高。旧视觉分析器的纯色块模型也能在开发集上输出部分尺寸。漏测集中在检测窗覆盖两个控件的场景。扫描主要看到面板的移动边及相邻控件，裁剪后可能缺少静止边；旧模型从变化区域选一种颜色、一个连通块，成功时即返回一个片段，失败时交给图层或刚性运动模型。这两条路径都可能将面板和相邻控件合并。旧留出集中的 16 个宽高变化均缺测。

新开关在原有裁剪预算内扩展候选区域，逐帧跟踪填充区域的左、上、右、下边界。边界间距沿一个轴改变时输出独立的 `size` 通道；宽高稳定且位置发生变化的相邻控件可单独形成 `translate` 片段。每个片段有自己的时间、扫过区域和证据帧。初始高度为零的插入项允许从最早可见的细条回推零高度。轨迹歧义、边界被裁、变化跳跃或剩余变化解释不足时回退。宽高样本可在函数包中按源像素查询，摘要和曲线共用同一批测量。

## 使用和重放

```powershell
motionspec analyze clip.mp4 -o out --layout-edges --functions
python bench/analyzer_eval.py --source browser --split m1-test --layout-edges --output result.json
```

Python 入口为 `analyze(..., layout_edges=True)`。去掉开关可复算原算法；`--source qt` 可重放 Qt。生成器的 `--m1-test` 使用既有留出家族顺序，种子统一偏移 30,000,000。重新采集时指定新的 `--output` 可以保留当前冻结视频。
